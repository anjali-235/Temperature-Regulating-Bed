# Temperature-Regulating Bed

## Project Description
A smart and adaptive bedding system that adjusts the bed temperature automatically based on user input and environmental conditions. The system ensures optimal sleeping conditions using smart contract-backed logic to store and manage user temperature preferences.

## Project Vision
To create a decentralized, user-friendly solution for enhancing sleep quality using dynamic temperature control integrated with blockchain for transparency and immutability.

## Key Features
- Set and store user-preferred bed temperature.
- Retrieve real-time temperature settings.
- Toggle activation state of temperature regulation.
- Immutable, tamper-proof records of user preferences.

## Future Scope
- Integration with IoT temperature sensors for real-time monitoring.
- Smart alerts and notifications for temperature anomalies.
- AI-based predictions for optimal temperature based on user sleep data.
- Multi-user support and advanced analytics on sleeping patterns.
